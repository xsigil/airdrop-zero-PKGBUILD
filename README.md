# airdrop-zero-PKGBUILD

Arch Linux PKGBUILD for building and installing the latest Git development version of [`airdrop-zero`](https://github.com/YOUR_GITHUB_USERNAME/airdrop-zero).

## Installation

### Manual Build

```bash
git clone [https://github.com/YOUR_GITHUB_USERNAME/airdrop-zero-PKGBUILD.git](https://github.com/YOUR_GITHUB_USERNAME/airdrop-zero-PKGBUILD.git)
cd airdrop-zero-PKGBUILD
makepkg -si

```
